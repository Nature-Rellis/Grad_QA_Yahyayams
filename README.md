Judul Tugas: 
Membuat Custom Gradle Task dan Mengelola Dependencies
Deskripsi Tugas:
Membuat proyek sederhana menggunakan Gradle dengan Groovy DSL dan Java. Proyek ini memiliki custom task bernama `greetingTask()` yang dapat menerima parameter Command Line Interface (CLI) menggunakan Gradle Project Property (`-Pname`).
Task tersebut akan menampilkan pesan sapaan berdasarkan nama yang diberikan pengguna. Selain itu, proyek menggunakan Google Guava versi 29.0-jre dan JUnit versi 4.13 sebagai dependencies.
Proyek kemudian dikelola menggunakan Git dan diunggah ke repository GitHub.
